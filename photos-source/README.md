# Logo et photos à fournir

Déposer ici les fichiers **bruts, pleine résolution, sans filtre ni recadrage**.
Le redimensionnement et l'optimisation pour le site sont faits ensuite.

## Logo

| Fichier | Format | Notes |
|---|---|---|
| `logo.svg` | vectoriel | Version principale, idéalement fond transparent. |
| `logo-fond-transparent.png` | PNG, ≥ 2000 px de large | Si pas de version vectorielle disponible. |
| `favicon-source.png` | PNG carré, ≥ 512×512 px | Pour générer le favicon (onglet navigateur). |

## Photos

Le cahier des charges ne précise pas encore de liste de prise de vue définie. À déposer au fur et à mesure, utile pour illustrer notamment :

| Sujet | Format suggéré | Usage |
|---|---|---|
| Portrait du fondateur (Maxime Lambelet) | vertical ou carré, ≥ 1600 px | Page "Qui sommes-nous" |
| Produits / recettes (Kobiji, etc.) | carré ou 4:3, ≥ 1200 px | Pages Activités |
| Atelier / production | horizontal, ≥ 1600 px | Pages Activités, Accueil |
| Événementiel / activation terrain | horizontal, ≥ 1600 px | Page Distribution et promotion |

Toutes facultatives pour le lancement — le site peut démarrer avec un habillage sobre sans photo si rien n'est prêt, et les visuels s'ajoutent ensuite sans changer la structure des pages.

## Consignes

- Lumière naturelle de préférence, éviter le flash direct sur les produits (reflets sur le verre/l'inox).
- Aucune banque d'images : cela se repère et nuit à la crédibilité recherchée par le site.

## Personnes photographiées

Toute personne reconnaissable (au-delà du fondateur lui-même) doit avoir donné son accord écrit avant publication.
